# FulviFetch: zorro frontal, versión 2

Esta es la imagen nueva aportada por el usuario, con las dos orejas de estructura
y detalles interiores similares. La imagen maestra se ha copiado sin cambios;
ya contiene fondo transparente. Esta exportación no utiliza generación de imágenes.

## Archivos

- `zorro-maestro.png`: original aportado, 1254 × 1254 píxeles, con transparencia.
- `icons/`: PNG de 16, 32, 48, 64, 96, 128, 256, 512 y 1024 píxeles.
- `zorro.ico`: ICO con imágenes de 16, 32, 48, 64, 128 y 256 píxeles.

Las exportaciones conservan la transparencia y se realizaron con:

```powershell
./media/exportar-iconos.ps1 -Source ./media/zorro-frontal-v2/zorro-maestro.png -Destination ./media/zorro-frontal-v2
```

La variante anterior se conserva solo localmente en `media/zorro-frontal/`.
